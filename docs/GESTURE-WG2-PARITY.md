# 鼠标手势：与 WGestures 2 的逐项对照

> 基准：`D:\Local AI\_归档\WGestures 2\src`（反编译源码）。
> 被对照方：`src\InputPlus`，采集时间 2026-11-24。
> **以 WG2 为准**：凡是两边不一致、且 WG2 的做法说得通的，一律改成 WG2 的做法。
> 表格里 `✅` = 已一致；`⚠️` = 有差异但代价/收益不明确，暂留；`❌` = 还没做。

## 七、仍未对齐（下一步）

1. **线宽 1.5 → 2.0**（一行）。
2. **标签位置**：跟随轨迹包围盒 + `Position` 默认 0.75。
3. **沿边再走一步**：20px / 250ms 的边缘步重触发。
4. **离开角落即结算**：WG2 在指针离开角落/边缘时立刻结算执行，Input Plus 没有这条路径。
5. **补点**：`GetMouseMovePointsEx`（32px 判据），快划时能补回被系统合并的移动。
6. **候选排序的 Level 规则**：WG2 按 `target.Level()` 升序 + 模板近似取高 Level；Input Plus 用 2/1/0 作用域覆盖。

## 八、本轮修掉的（2026-11-24）

| 症状 | 真因 | 改动 |
|---|---|---|
| 手势轨迹完全不显示 | 绘制代码在 `if (!add) return;` 之后，而 `add` 的基准点被钩子线程实时顶到光标旁边 → 几乎永远 false | 新增 `PaintTrail`，每拍都喂；钩子采到的点也逐个补 |
| 多笔手势触发后轨迹不变色 | `MarkRecognized()` 与 `ShowLabel(keepTrail:false)` 在同一帧，颜色刚改完线就被清掉 | `PreviewSteps`：每收一段做前缀识别，唯一命中即变色（WG2 的"认出即变色"） |
| 角上那一下常认错 | corner / edge 两套独立判定，角内同时成立 | `WgZoneTracker` 逐行移植 `A/O.cs` |
| 长笔画被 8 秒中断 | 兜底判据用 `_activeSince`（按下时刻） | 改用 `_lastMoveAt` |
| 通配手势"立即执行"不生效 | `Match` 无条件跳过通配，那段是死分支 | 加 `allowWildcard` |
| 设置里"统一色"选了没反应 | 绘制侧只读分键色 + `PathColorNormal` | 加 `TrailColorSet`，绘制认它 |
| 识别与上游不是一个尺子 | 识别链路多了滑动平均 + RDP | 去掉两步（对齐 `A/P.cs` 的输入口径） |
| 实时识别慢半拍 | 6 点 / 60ms 节流 | 每点一次 |
| 多笔只能靠停顿切段 | 松手即结算 | 加 900ms 待命窗口（同键再按下接第二笔） |
